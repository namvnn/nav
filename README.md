# Nav

Nav is an opinionated, Vim-like modal text editor, built for myself. It focuses
on Vim/Neovim's features that I need.

## Acknowledgement

- [Build Your Own Text Editor](https://viewsourcecode.org/snaptoken/kilo) is a
  booklet by [Paige Ruten](https://github.com/paigeruten) that inspires me to
  build my own text editor.
